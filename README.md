# Comprehensive Clinical Data Analysis Project:

## Project Overview:

This project demonstrates a complete, end-to-end workflow for Clinical Data Management (CDM) and analysis using Microsoft Excel. It simulates a real-world clinical trial scenario, structured as a three-stage process: from cleaning raw data to applying analytical formulas and finally building an interactive summary dashboard.

## Project Files:

1. Raw Data.xlsx: The initial, unprocessed multi-sheet dataset containing intentional errors for cleaning and validation practice.
2. Clinical_Excel_Project_Solved.xlsx: The final workbook containing the complete workflow, including the cleaned data, formula applications, and the final interactive dashboard.

## Key Skills & Tools Demonstrated:

1. Data Cleaning and Preparation: Standardization of text and formats, duplicate removal, handling of missing values, and outlier detection.
2. Advanced Formulas: Application of logical (IF, AND), lookup (VLOOKUP), and statistical (COUNTIFS, AVERAGEIFS) functions to derive variables and perform quality checks.
3. Data Summarization: Extensive use of PivotTables and PivotCharts to aggregate data. 
4. Data Modeling and ETL:
     -  Power Pivot: Used to create relationships between the Demographics, Labs, Visits, and Adverse Events tables to build a central, relational data model.
5. Dashboarding and Visualization: Creation of an interactive dashboard featuring KPI cards, charts (Bar, Line, Pie), and slicers for dynamic filtering of clinical trial metrics.

## Project Workflow: A Three-Stage Process

This project was executed in three distinct stages, reflecting a standard data analysis lifecycle.

### Stage 1: Data Cleaning
The primary objective was to refine the Raw Data.xlsx file. This foundational step involved transforming the raw, inconsistent data into a clean, structured, and reliable dataset ready for analysis. Key tasks included removing duplicates, standardizing text and formats, correcting data types, and handling missing values.

### Stage 2: Formula-Based Analysis
Using the cleaned dataset, this stage focused on deriving analytical insights and performing quality checks using a range of Excel formulas. Around 11 different formulas were applied to answer specific clinical data questions. For educational purposes, the questions themselves are included as notes in the corresponding cells within the Clinical_Excel_Project_Solved.xlsx file.

### Stage 3: Interactive Dashboard Creation
This final stage culminates in the creation of a dynamic dashboard for high-level monitoring. Using the analyzed data, a comprehensive visual summary was built, incorporating:
-   PivotTables and PivotCharts to summarize key metrics.
-   KPI Cards to display critical indicators like patient counts and AE rates.
-   Slicers to enable interactive filtering of the entire dashboard by parameters such as treatment group, site, and gender.

## How to Use:

1. Raw Data.xlsx: Use this file to replicate the project's data cleaning and analysis steps from scratch.
2. Clinical_Excel_Project_Solved.xlsx: Open this file to explore the final dashboard and the complete solution.
    -   Navigate to the formula sheet and hover over the cells to view the questions that were solved, which are embedded as notes.
    -   Use the slicers on the Dashboard sheet to interactively filter the data.
